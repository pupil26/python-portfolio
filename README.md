## 作品清单

### 1. 网页变化监测 + 表单预填（`webwatch/`）

- **`web_monitor.py`** — 零依赖网页变化监测：抓取 → 指纹计算 → 变化提醒 → 快照存档
  - 纯标准库，`python web_monitor.py` 直接跑，不用 `pip install`
  - 已用真实公网页面验证
- **`form_filler.user.js`** — 油猴表单预填脚本，一键填表，只预填不提交
  - 用原生 setter 触发事件，兼容 React/Vue 受控组件（很多同类脚本做不到）

### 2. 古钱币版别识别（`coin/`）

- **`coin_match.py`** — OpenCV 实现的版别识别 Demo
  - 圆形轮廓提取（Hough 圆 + 掩码）
  - ORB 特征旋转/缩放对齐（`estimateAffinePartial2D` + RANSAC 抗离群）
  - ROI 局部特征比对
  - 核心思路：**ORB 抓「字形结构」、SSIM 只看「亮度」，两者解耦**，避免锈色/包浆干扰误判
